Task: Create three API endpoints using Express.js.
Method	Endpoint	Requirement
GET	/students	Return all students
GET	/students/:id	Return a student by ID
POST	/students	Add a new student

Requirements:
- Use express.json() to parse JSON requests.
- Return 404 if the student ID doesn't exist.
- Validate that name and marks are provided.
- Return 201 when a student is created.
- Generate a unique ID for each new student.
Follow-up Viva Questions
1. What is the difference between req.params and req.body?
2. Why do we need express.json()?
3. What happens if the client sends a student ID that doesn't exist?
4. Why should POST return status code 201 instead of 200?
5. What happens to the newly added students when the server restarts?
Suggested duration: 10–15 minutes.

Bonus challenge: Implement GET /students/pass to return only students whose marks are greater than or equal to 40.
