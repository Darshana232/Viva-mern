Task: Create three API endpoints using Express.js.
Method	Endpoint	Requirement
GET	/students	Return all students
GET	/students/:id	Return a student by ID
POST	/students	Add a new student

Requirements:
- Use express.json() to parse JSON requests.
- Return 404 if the student ID doesn't exist.
- Validate that name and marks are provided.
- Return 201 when a student is created.
- Generate a unique ID for each new student.
